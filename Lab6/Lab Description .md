## Lab 6 — Regularization: Closing the Gap

- **Aim:** Understand overfitting and improve neural network generalization.
- **Main tasks:**
  - Use training, validation, and test sets to evaluate performance.
  - Implement L1 and L2 regularization and inverted dropout.
  - Explore weight initialization, including He initialization.
  - Implement the forward pass of batch normalization.
  - Compare regularization methods using loss curves and decision boundaries.
- **Tools:** Python, NumPy, Matplotlib, and TensorFlow Playground.
