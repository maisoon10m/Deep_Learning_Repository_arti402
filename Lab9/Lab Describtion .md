## Lab 09 — Autoencoders: Learning Without Labels

This lab explores **Autoencoders** and unsupervised representation learning using handwritten digit images. It covers building and training an Encoder–Decoder architecture, evaluating reconstruction quality with Mean Squared Error (MSE), and investigating how bottleneck size affects compression and reconstruction. It also examines latent representations for classification using Logistic Regression and introduces **Denoising Autoencoders** to reconstruct clean images from noisy inputs.
