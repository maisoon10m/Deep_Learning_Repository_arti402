## Lab 7 — TensorFlow and Keras

- **Aim:** Build and train neural networks using TensorFlow and Keras.
- **Main tasks:**
  - Build, compile, train, and evaluate a neural network.
  - Apply L2 regularization and dropout.
  - Use early stopping to restore the best model weights.
  - Prepare training data using `tf.data`.
  - Save and reload models, verifying consistent predictions.
  - Compare regularization methods using loss curves and decision boundaries.
- **Tools:** Python, TensorFlow, Keras, NumPy, and Matplotlib.
